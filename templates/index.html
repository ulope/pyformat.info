PyFormat Using %, .format() and f-strings for great good!

Show: {% for flavor in flavors if flavor.selectable %} {% endfor %}

Python has had awesome string formatters for many years but the documentation on them is far too theoretic and technical. With this site we try to show you the most common use-cases covered by %-formatting, .format() and f-strings with practical examples.

.format() and f-strings share the same format specification: everything after the : works the same in both. Use the buttons at the top to choose which styles you want to see.

All examples are tested with Python 3.14 and don't require any additional libraries. f-strings need Python 3.6 or newer, features that need an even newer version are marked.

If you want to contribute more examples, feel free to create a pull-request on Github!
